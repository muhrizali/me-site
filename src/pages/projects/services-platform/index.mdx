This project mainly consists of two independent projects which works similarly to one another. Both of these projects were part of my Diploma course and were a requirement to complete it.

The first project was mainly made with the Python micro web-framework Flask to create a multi-page application that allows users to book various household services for their homes. There were mainly three parties involved in the platform; the customers who book the services, the professionals who provide the services and the admin team that manages them both.

Source: [Household-Services GitHub](https://github.com/muhrizali/Household-Services)

The second project was similar to the first one in features and functionality, it was made with the same Flask backend but core end-user interaction was different. This is because the project was a single-page application made with JavaScript frontend framework VueJS. To be honest, this is the project that made me realize the potentials and huge drawbacks of JavaScript than any other thing.

Source: [Household-Services-V2 GitHub](https://github.com/muhrizali/Household-Services-V2)
