I remember I have made three versions of this simple application with similar functionality but different data backends. One saves the data inside a (probably unsafe) binary file, local SQL database and a remote SQL database (spun up server through Heroku at the time).

I remember I have made this project on my aunt's 9 year old laptop in 2-3 days because I was in my hometown. Schools were closed due to COVID and I used to constantly update my other team member (my best friend at the time) about little fixes and our presentation. Good times.
